本レポートは、IT監査およびAIガバナンス担当者が「管理対象とすべき変更点」を特定することを目的としています。

2. ChatGPT / OpenAI

新規 GPT-6 Astra
次世代モデル「GPT-6 Astra」が発表されました。監査視点では、既存のガバナンス環境が本モデルの複雑性（エージェント機能等）に対応可能か、導入前のリスク評価が必要です。

新規 ChatGPT for Financial Services
金融業界向けに最適化された機能が公開されました。業界規制を遵守するためのデータフローが標準機能として担保されているか確認してください。

変更 Work Modeの不具合
13日に発生したエラー報告が確認されています。業務自動化ツールとしての利用において、可用性と処理結果の整合性に対する耐障害性の確認が求められます。

3. Gemini / Google

新規 Gemini for Windows公開
Windows用アプリの提供が開始されました。ブラウザ利用とは異なる「OSネイティブアクセス」が発生するため、端末管理（MDM）や認証トークンの保持状況の監査が必要です。

4. Claude / Anthropic

新規 Claude Fable/Mythos 5.1リリース
新モデルが提供開始されました。利用ガイドラインにおけるプロンプト設計の変更や、出力検証プロセスの見直しを推奨します。

継続 AI悪用対策（9月報告）
不正利用監視に関する報告が公開されました。自社のAI利用ポリシーにおける「禁止行為」リストを、最新の脅威傾向と照合してください。

5. Microsoft Copilot

新規 CopilotにGrokを統合
Copilotにおけるモデル選択肢が拡大しました。モデルごとに挙動やデータプライバシー設定が異なる可能性があるため、組織として「どのタスクにどのモデルを許可するか」の制御設定を再確認してください。

新規 Azure Copilot: Troubleshooting Agent
トラブルシューティングエージェントが一般公開されました。システム運用ログをAIが自動解析するリスクがあるため、機密情報がログに含まれる場合のマスキング処理の有効性を確認してください。

6. 内部監査への示唆

  • ガバナンス：モデルの選択肢が増える（Grok等の統合）ことで、企業が求める安全性レベルを満たさないモデルが選択されるリスクが生じています。一元的な制御ポリシーの適用が急務です。
  • アクセス管理：OSネイティブアプリ（Gemini for Windows等）が増加しており、従来のブラウザ閲覧のみを前提としたセキュリティ設定では不足する可能性があります。

7. 今後ウォッチすべき事項

  • GPT-6等の次世代モデル導入における、企業データ保護基準（GDPR/APPI等）との整合性。
  • 各AIベンダーが提供する「金融」や「トラブルシューティング」等のドメイン特化型エージェントの、実業務における誤検知率とハルシネーションの影響調査。
