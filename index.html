本レポートは、IT監査およびAIガバナンス担当者が「管理対象とすべき変更点」を特定することを目的としています。

2. ChatGPT / OpenAI

新規 ChatGPT for Financial Services
Morgan Stanleyとの共同開発による金融業界向けChatGPTが発表されました。内部監査としては、特に「金融コンプライアンス（秘匿性）が担保された環境で、どのようなデータが外部（OpenAI）に送られるか」のデータフロー図の更新が必須です。

3. Gemini / Google

新規 Gemini for Windows
Windowsデスクトップアプリとして展開。Webブラウザ版とは異なる「OSネイティブの実行環境」となるため、端末内のキャッシュ管理や、Windows環境におけるAPI呼び出し時の認証制御をIT全般統制の対象に追加してください。

4. Claude / Anthropic

継続 AI悪用対策の強化
Anthropicは、国境を越えたスパイ活動や兵器プロジェクトでの悪用事例について、継続的な監視体制を強化しています。自社開発のAIアプリケーションにClaude APIを組み込んでいる場合、Anthropic側が提供する「不正使用検知」のログを自社ログと照合可能か検討してください。

5. Microsoft Copilot

変更 ドメイン除外制御の復旧
Web検索（Grounding）におけるドメイン除外機能が再導入されました。管理者による「検索禁止先リスト」の更新が適切に行われているか、その設定変更の承認フローが変更管理規程に準拠しているかを確認してください。

6. 内部監査への示唆

  • AIガバナンス：エージェント化が進むにつれ「AIが自律的に実行した処理」の追跡が必要です。ログには「モデル名」「実行プロンプト」「参照されたデータソース」の3点を必ず記録してください。
  • IT全般統制：今回のように「Word/ExcelへのGrok統合」等のアプリ変更は、従来のパッチ管理だけでなく、AIのパラメータ変更（システムプロンプト）の監視が必要です。
